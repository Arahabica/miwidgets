miwidgets — HTML widget templates for Muse chat bubbles

## How to register

Save every template below as a file, byte for byte. Download each URL directly to disk.
The URLs return the source as plain text.
Do not copy the source through the chat or from a rendered page; long lines and
base64 data will break.
Record where you saved the templates and the version from version.txt in a note
that persists across sessions.

## Rules

- Copy the template source as is. Change only the values inside `var data = {...}`.
- Do not change the HTML, CSS, JavaScript or design.
- The sample images in `IMAGES` are 30px placeholders. Never show them. Replace them with the user's images, or remove the image from `data` if there are none.
- The templates are in Japanese by default. When the user writes in English, set `lang` to 'en' in `data` if it has one, and write every string in `data` in English.
- Before each use, fetch https://miwidgets.com/version.txt. If the number has changed since you last fetched the templates, fetch them again.

https://miwidgets.com/template/route.html

Stock chart — profit and loss over time as a line chart, with a legend per holding
https://miwidgets.com/template/assets.html

Quiz — a multiple-choice quiz app
https://miwidgets.com/template/quiz.html

Analog clock — an analog clock with a second hand
https://miwidgets.com/template/clock.html

Calendar — one month, with a mark (◯ △ x -) or up to 2 characters on each day
https://miwidgets.com/template/calendar.html

Time slots — 7 days × times (every 15, 30 or 60 minutes), with a mark (◯ △ x -) or up to 2 characters in each slot
https://miwidgets.com/template/timetable.html

Bar chart — a title and values per item as bars, any number of series side by side, each with an optional color; tap an item to see its values
https://miwidgets.com/template/bar.html

Line chart — a title and values over time as lines, any number of series, each with an optional color; tap a point to see its values
https://miwidgets.com/template/line.html

Pie chart — a title and values per item as slices of a circle, each with an optional color; shares are worked out from the total; names and shares go inside the slices or on leader lines, with a table of values below; tap a slice to highlight it
https://miwidgets.com/template/pie.html

Ranking — a title and values per item, sorted from largest to smallest and shown as horizontal bars; 1st to 3rd get gold, silver and bronze ribbons; equal values share a rank
https://miwidgets.com/template/ranking.html

Data sheet — rows and columns as a table or a two-column list; viewers can sort by a column and choose which columns to show
https://miwidgets.com/template/sheet.html

Omikuji fortune — a Japanese fortune-slip app
https://miwidgets.com/template/omikuji.html

Secret message — a message that opens with a 6-digit passcode
https://miwidgets.com/template/secret.html
