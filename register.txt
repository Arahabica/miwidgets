miwidgets — HTML widget templates for Muse chat bubbles

## How to register

Fetch the source of every template below from its URL and save it as is.
Do not use the pages under miwidgets.com/template/. They are rendered previews, not the source.

## Rules

- Copy the template source as is. Change only the values inside `var data = {...}`.
- Do not change the HTML, CSS, JavaScript or design.
- The templates are in Japanese by default. When the user writes in English, set `lang` to 'en' in `data` if it has one, and write every string in `data` in English.
- Before each use, fetch https://miwidgets.com/version.txt. If the number has changed since you last fetched the templates, fetch them again.
